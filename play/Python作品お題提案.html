🧩 コード解説

① response = requests.get(url)

👉 Webサイトにアクセスして、ページの内容を取得する部分。

  • requests は、PythonでWebページのデータを取得するためのライブラリ。

  • .get(url) は指定したURL（例：https://news.yahoo.co.jp/）の内容を取りに行く命令。

  • 返り値の response には、Webページ全体のHTMLデータが入ります。

例：

python
print(response.status_code)
# 200 → 正常に取得できた

② soup = BeautifulSoup(response.text, "html.parser")

👉 取得したHTMLを、Pythonで扱いやすくするための変換。

  • response.text は、Webページの中身（HTMLの文字列）。

  • BeautifulSoup() は、そのHTMLを解析して、「ツリー構造」で扱えるようにします。

  • "html.parser" は、Pythonに内蔵されたHTML解析エンジン。

つまりこの行で、soup が「HTMLを操作できるオブジェクト」になります。

③ ("a.newsFeed_item_title")

👉 HTML内の特定の要素を探すための“CSSセレクタ”。

  • a は HTML の <a> タグ（リンク）。

  • .newsFeed_item_title は、そのタグに付いているクラス名。
    つまり、「クラス名が newsFeed_item_title のリンク」を探しています。

例えばこんなHTMLがあったとします：

html
<a class="newsFeed_item_title" href="https://example.com">ニュースタイトル</a>

これが検索にヒットします。

使い方はこう👇：

python
titles = soup.select("a.newsFeed_item_title")

これで該当する <a> タグのリストを取得できます。

④ t.text

👉 HTMLタグの中の「文字部分」だけを取り出す。

例えば：

html
<a href="#">今日のニュース</a>

というタグがあるとき、
soup.select("a")[0].text は "今日のニュース" になります。

つまり .text は、タグの中のテキストだけを取り出すための便利なプロパティです。

🧩 BeautifulSoupって何するの？

WebページのHTMLを「ツリー構造」で解析して、
特定のタグやテキストを簡単に取り出すためのツールです。

たとえば：

python
from bs4 import BeautifulSoup

html = """
<html><body>
<h1>ニュース一覧</h1>
<a class="news" href="https://example.com/1">ニュース1</a>
<a class="news" href="https://example.com/2">ニュース2</a>
</body></html>
"""

soup = BeautifulSoup(html, "html.parser")

titles = soup.select("a.news")
for t in titles:
    print(t.text, "→", t.get("href"))

from bs4 import BeautifulSoup

print("🌤️ 天気:", weather)

import requests
